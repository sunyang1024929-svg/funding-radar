# 融资雷达网站设计

## 目标

将每日更新的融资记录发布为可分享的 GitHub Pages 静态网站，方便团队按公司、行业、融资时间和金额浏览近期机会。

## 架构

网站使用纯 HTML、CSS 和浏览器原生 JavaScript。构建脚本从 `data/funding-records.json` 生成 `site/data/funding.json`；页面加载该文件并在浏览器端完成搜索、行业筛选和中国/全球市场切换。Excel 继续作为可下载的审阅副本。

GitHub Actions 在推送到 `main`、每日定时触发或手动触发时运行测试、生成 Excel 与网站数据，并发布 `site/` 到 GitHub Pages。

## 页面

- 顶部显示“融资雷达”、最后更新时间和数据范围。
- 主工作区默认显示中国公司，全球公司通过市场切换查看。
- 搜索匹配公司、行业、融资轮次与来源网站。
- 行业下拉框和最近 7/30/90 天时间范围筛选。
- 表格展示公司名称、行业、最新融资时间、融资规模、融资轮次、人民币换算金额和来源。
- 来源链接在新标签打开；无披露金额保留原文，不虚构数值。

## 数据与错误处理

- 构建时复用现有去重和人民币换算逻辑。
- 如数据文件为空，网站显示空状态而不报错。
- 若浏览器加载数据失败，显示明确提示与重试按钮。

## 验证

- Node 测试覆盖公开数据导出、市场分组和金额展示。
- 本地 HTTP 服务下检查页面加载、筛选和来源链接。
